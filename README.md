# AutoCut

Автоматическая сборка черновика монтажа для Premiere Pro.

Панель в Premiere — единственный интерфейс. Локальный движок анализирует
материал, строит план, отдаёт редактируемую секвенцию и, позже, готовый
MP4. Всё считается на машине монтажёра: кадры и речь никуда не уходят.

> **Статус:** ветка `v2`, идёт переделка. Версия `v1` заморожена тегом
> `v1`. Старое окно на Tk, MCP-интерфейс и лишние режимы удалены.
> Сейчас работает панель, движок и сокращённый набор тестов. Первый
> сквозной сценарий v2 — дайджест — собирается в M1.

## Требования

- Windows 10/11
- Python 3.11+
- **ffmpeg** и **ffprobe** в PATH
- Premiere Pro 2026 (CEP-панель)
- NVIDIA GPU с 6 ГБ VRAM — желательно; без неё часть моделей уйдёт на CPU
  и будет заметно медленнее

```bash
pip install -r requirements.txt
```

Модели скачиваются при первом запуске и занимают несколько гигабайт:
Whisper `large-v3`, Qwen2-VL-2B для описания кадров, e5-large для тем.
Установщик для других монтажёров, который скачивает их с прогрессом, —
это M4.

## Запуск

1. Поставить панель:

```bash
cd plugin
python -c "import sys; sys.path.insert(0,'src'); import bootstrap; from mcp_server import premiere_install; print(premiere_install.install_panel())"
```

2. Перезапустить Premiere.
3. Открыть `Window → Extensions → AutoCut`.
4. Указать папку проекта, хронометраж и нажать «Собрать дайджест».

Панель сама найдёт движок и запустит его. Если движок не поднялся,
кнопка «Проверить движок» покажет, чего не хватает: Python, ffmpeg,
модулей, модели или места на диске.

`AutoCut.bat` запускает движок вручную — это запасной путь для отладки.

## Как это устроено

```
plugin/
  premiere_panel/        CEP-панель: единственный UI
  engine/                новый тонкий движок v2
    api.py               HTTP для панели
    index.py             единый индекс материала
    director.py          структура истории и выбор кандидатов
    editor.py            таймлайн, дорожки, длительности
    packs/               жанровые правила: дайджест, интервью, репортаж
    export/xml.py        FCP7 XML
    export/render.py     MP4 через ffmpeg
    doctor.py            проверка окружения
  src/                   проверенное ядро v1, которое переносится в engine
    ml/                  речь, кадры, качество, темы, рекордер
    io/premiere.py       экспорт FCP7
    modes/               текущие пайплайны дайджеста и интервью
    mcp_server/          временный транспорт панели, будет заменён на engine/api.py
```

Правило v2: **один жанр — один пак настроек, а не отдельная копия
пайплайна.** Общий путь: папка → индекс → `edit_plan.json` → таймлайн →
XML и MP4.

`mcp_server/` пока остаётся, потому что через него панель разговаривает
с движком. В продуктовой архитектуре его заменит `engine/api.py`; MCP
как отдельный интерфейс больше не развивается.

## Что удалено в v2

- окно на Tk и все страницы `ui/`;
- режимы «новости», «разбор готового», «повествование», «вертикаль»,
  «мультикам», «плашки», «музыка»;
- старый планировщик `modes/autocut.py`;
- `prproj.py`, `preview.py`, `premiere_compat.py`, `recvoice.py`;
- тесты и документация под удалённые режимы.

Вертикаль и мультикам — не жанры, а формат вывода и раскладка источника.
Их вернём позже отдельными возможностями, а не клонами пайплайна.

## Тесты

```bash
cd plugin
python run_tests.py
```

Сейчас 18 тестов. Признак успеха — код возврата 0 и финальная строка
`Все 18 тестов прошли`. Упавший тест успевает напечатать несколько `OK`,
поэтому проверять только наличие слова `OK` нельзя.

## Ограничения

- **FCPXML Premiere не импортирует.** Формат — FCP7 (xmeml v5).
- **`<multiclip>` Premiere 26 не читает.** Рабочий путь — две видеодорожки.
- **У каждого клипа обязан быть `<file>`.** Иначе Premiere молча
  отказывается импортировать весь XML.
- **Универсальность — это ядро и паки, а не «любое видео одной кнопкой».**
  Первый пакет — дайджест, второй — интервью, третий — репортаж.
- **Модели не влезают в 6 ГБ одновременно.** Движок загружает их по
  очереди и освобождает память.
