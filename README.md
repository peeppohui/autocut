# AutoCut

Автоматическая нарезка видео. Сырьё на входе —
часы записи с нескольких камер и микрофонов. На выходе — смонтированная
рыба, готовый XML для Premiere Pro и субтитры.

Работает целиком локально: ни один кадр и ни одно слово никуда не
отправляются.

---

## Что он делает

| Шаг | Что происходит |
|---|---|
| **Синхронизация** | Камеры и микрофоны сводятся к общей шкале времени по перекрёстной корреляции звука. Хлопок в ладоши не нужен |
| **Распознавание речи** | Whisper распознаёт речь по каждому микрофону отдельно, так что видно, кто говорил |
| **Чистка** | Убираются паузы, слова-паразиты, повторы, заикания и «э-э-э». Неуверенные слова не выбрасываются молча, а помечаются `[!]` |
| **Отсев пустых кадров** | Если камера не была включена, куски с тишиной и чёрным кадром уходят |
| **Подгонка хронометража** | Куски отбираются под заданную длительность. Сначала режется техническое и перебивки, потом слабое по смыслу; зачин и концовка не трогаются |
| **Раскладка кадров** | Покадровая оценка крупности через YOLO-pose, выбор ракурса по говорящему |
| **Экспорт** | FCP7 XML для Premiere, отдельная дорожка звука на каждый микрофон, субтитры, маркеры с причиной каждой склейки |
| **Таймлайн** | Дорожки монтажа как в Premiere: выкинуть кусок или поменять ракурсы прямо в окне, без Excel |

## Требования

- Windows, Python 3.11+
- **ffmpeg** в PATH — без него не запустится ни синхронизация, ни экспорт
- Premiere Pro (для финальной сборки; сам монтаж готовится без него)

```bash
pip install -r requirements.txt
```

Зависимости тяжёлые: `ultralytics` тянет PyTorch (~500 МБ), модель
Whisper качается сама при первом запуске (~150 МБ для `base`).

## Запуск

Двойной клик по **`AutoCut.bat`**. Откроется окно со списком шаблонов
слева.

Отдельные шаги можно гнать и из консоли:

```bash
cd plugin

# синхронизация камер и микрофонов
python -m src.ml.sync --ref общий.mp4 --cam гость.mp4 \
    --mic-guest гость.wav --mic-host ведущий.wav --outdir out/synced

# рыба по тексту
python -m src.modes.interview --wide out/synced/ref.mp4 \
    --guest-cam out/synced/cam.mp4 --outdir out/rz

# экспорт для Premiere
python -m src.io.premiere --timeline out/rz/selects.csv --out ryba.xml --stacked
```

## Как это устроено

```
plugin/src/
  ui/       окно и оформление
  modes/    что делаем: интервью, дайджест, сюжет, разбор
  ml/       модели: синхронизация, детекция лиц, чёрные кадры, музыка
  io/       выход: XML для Premiere, субтитры, превью
  config/   настройки в settings.json
```
Настройки лежат в `plugin/src/config/settings.json`. Их можно править
руками или прямо в окне, на странице «Настройки».

## Правка результата

Самый полезный режим — собрать сначала транскрипт, вычеркнуть мусор
руками и только потом собирать рыбу:

```bash
python -m src.modes.interview --transcript-only ...
```

В `transcript.txt` строка, начинающаяся с `-`, в монтаж не попадёт.

## Тесты

```bash
cd plugin
python run_tests.py
```

Признак успеха — код возврата 0. Обычный перебор тестов здесь обманывает:
упавший тест успевает напечать несколько `OK` перед падением, и такой
прогон выглядит зелёным.

## Ограничения

Часть вещей Premiere не умеет, и обойти это удалось не для всего:

- **FCPXML не импортируется вообще.** Формат — FCP7 (xmeml v5).
- **`<multiclip>` Premiere 26 не читает.** Проверено на четырёх вариантах
  структуры. Рабочие пути — две видеодорожки с переключением, либо
  общий таймкод в файлах и ручное создание мультикама в Premiere.
- **У каждого клипа обязан быть `<file>`.** Без него Premiere молча
  отказывается импортировать весь файл, без объяснений.
- Камера, пойманная в момент включения, даёт куски без картинки — их
  лучше снять заранее вручную или положиться на автоотсев.

Подробности о граблях, на которые уже наступали, — в
[AGENTS.md](AGENTS.md).

## Хотите помочь с разработкой

Это вполне возможно, и помощь реально нужна. С чего начать:

1. Поставьте зависимости и прогоните тесты — они должны пройти целиком.
2. Прочитайте [AGENTS.md](AGENTS.md). Там собрано то, что неочевидно:
   какие ограничения у Premiere Pro, почему у каждого клипа обязан быть
   `<file>`, как проверять, что новый экспорт вообще грузится. Без этого
   легко потратить день на выяснение того, что уже выяснено.
3. Загляните в открытые задачи — их легко найти среди Issues.

Что нужно проекту в первую очередь:

| Задача | Почему |
|---|---|
| **Режим телешоу** | 5 камер и 8 микрофонов. Решения нет, есть только общие соображения |
| **Распознавание вне эфира** | Сейчас режет всё подряд; понимать, что идёт в эфир, а что нет |
| **Лицензия** | Своя, но если проект пойдёт в массы, понадобится внятная |

Проверять изменения просто:

```bash
cd plugin
python run_tests.py
```

Если трогаете экспорт для Premiere — тестируйте на настоящем файле,
а не только на тестах: часть граблей видна только при реальном импорте,
и о них написано в AGENTS.md.
