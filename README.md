# AutoCut

Автоматическая сборка черновика монтажа для Premiere Pro.

Панель в Premiere — единственный интерфейс. Локальный движок анализирует
материал, строит план и отдаёт **две** секвенции: «Сбор (AutoCut)» —
собранный материал, и «Отбор» — все исходники, которые в сборку не
попали, чтобы монтажёр мог подменить неудачные кадры. Всё считается на
машине монтажёра: кадры и речь никуда не уходят.

## Как это выглядит

Панель в Premiere (CEP, без React и без внешних зависимостей) собрана по
макету бренда:

- **карточка источника** — папка, число клипов и их суммарная длительность
  (кнопка «Сменить» открывает выбор папки);
- **чип типа ролика** — «Дайджест»;
- **слайдер длительности** — 15…180 секунд, рядом монтаймкод;
- **четыре тумблера** — убрать паузы, убрать дубли, оставить лучшие моменты
  речи, резать под бит музыки;
- **кнопка «Собрать рыбу»** — дальше панель сама следит за задачей и импортирует
  готовые секвенции в проект;
- **футер-черновик** — честный мини-таймлайн сборки: блоки по частям
  (стендап, интервью, нарезка, музыка) в масштабе хронометража, и строка
  «Вместо 3 ч 42 мин отсмотра — 95 с готовой „рыбы“».

Собранный XML и план лежат рядом: `autocut_out/plan.csv`, `ryba.xml`,
`ryba_otbor.xml`, `ryba.edl`, `shelf.csv`.

## Требования

- Windows 10/11
- Python 3.11+
- **ffmpeg** и **ffprobe** в PATH
- Premiere Pro 26 (CEP-панель)
- NVIDIA GPU с 6 ГБ VRAM — желательно; без неё часть моделей уйдёт на CPU
  и будет заметно медленнее

```bash
pip install -r requirements.txt
```

Модели скачиваются при первом запуске и занимают несколько гигабайт:
Whisper `large-v3` (речь), Qwen2-VL-2B (описание кадров), e5-large (темы).

## Установка

1. Поставить панель:

```bash
cd plugin
python -c "import sys; sys.path.insert(0,'src'); import bootstrap; from mcp_server import premiere_install; print(premiere_install.install_panel())"
```

2. Перезапустить Premiere.
3. Открыть `Window → Extensions → AutoCut`.
4. Указать папку проекта, хронометраж и нажать «Собрать рыбу».

Панель сама находит движок и запускает его. Если движок не поднялся,
кнопка «Проверить движок» покажет, чего не хватает: Python, ffmpeg,
модулей, модели или места на диске.

`AutoCut.bat` запускает движок вручную — это запасной путь для отладки.

## Что происходит при сборке

1. **Инвентаризация.** Материал раскладывается по папкам частей: `стендап`,
   `интервью`, `нарезка`; отдельно находится папка со звуком рекордера
   (`REC*.WAV`) и mp3 для подложки.
2. **Речь.** Whisper разбирает речь, из неё собираются слова с таймкодами.
   Для интервью выбирается **лучший монолог** спикера — самый длинный
   связный заход речи, а паузы внутри него вырезаются.
3. **Синхрон с рекордером.** У дублирующихся кадров текст одинаковый, поэтому
   словесный матч даёт только кандидатов, а подтверждает пару **огибающая
   звука**: камера и рекордер сверяются по форме сигнала. Так сдвиг
   получается верным даже на дублях. Спикер, у которого нет звуковой пары с
   рекордером, в сборку не берётся.
4. **Монтаж.** Стендап → пауза 3.6 с → первый спикер → пауза 13 с →
   второй спикер. Перебивки кладутся: не больше трёх **над интервью** и не
   больше пяти **в паузе между спикерами**, куски 1.2–2.6 с. Первые 8 секунд
   нового спикера остаются открытыми, последние 2.2 с стендапа перебивка
   накрывает (J-cut).
5. **Звук перебивок — отдельный.** У перебивок **нет своего звука**: под
   речью звучит рекордер, в паузах — музыка. Иначе шум зала глушил голос
   интервью.
6. **Музыка.** mp3 из корня материала (или `digest.music` в настройках)
   кладётся на дорожку A3 от нуля до конца голоса и **приглушается** на
   стендапе и интервью — приглушенная копия делается ffmpeg-ом, исходник не
   трогаем.
7. **Ритм (по тумблеру).** Свой детектор битов (без librosa) снимает сетку
   ударов с музыки — на треке «It's The Sims» выходит 76 BPM — и монтажные
   точки встают на доли такта, а длины кусков становятся кратны доле.
8. **Отбор.** Всё, что не попало в сборку, собирается в секвенцию «Отбор»
   подряд, со своим звуком, — чтобы можно было смотреть исходники и
   подставлять их в монтаж вручную.

## Как это устроено

```
plugin/
  premiere_panel/        CEP-панель: единственный UI
    index.html           разметка и стили (без внешних зависимостей)
    panel.js             логика: сборка, слежение за задачей, импорт XML
    host.jsx             ExtendScript-хост для диалогов Premiere
    assets/              логотип и шрифты (Manrope, JetBrains Mono)
  engine/                тонкий локальный движок
    api.py               HTTP для панели: /health, /action, /task, /command
    jobs.py              одна очередь задач, журнал, отмена
    actions.py           дайджест, интервью, материал, сводка, доктор
    material.py          разбор папки с материалом
  src/                   ядро анализа
    ml/                  речь, кадры, качество, темы, рекордер, beat.py
    io/premiere.py       экспорт FCP7 (xmeml) и EDL
    modes/               пайплайны дайджеста и интервью
    mcp_server/          установщик панели и обёртки старых импортов
```

Правило v2: **один жанр — один пак настроек, а не копия пайплайна.**
Общий путь: папка → индекс → план → таймлайн → XML.

## Ограничения

- **FCPXML Premiere не импортирует.** Формат — FCP7 (xmeml v5).
- **`<multiclip>` Premiere 26 не читает.** Рабочий путь — две видеодорожки
  с переключением глазком.
- **У каждого клипа обязан быть `<file>`.** Иначе Premiere молча
  отказывается импортировать весь XML.
- **Чипы «Рилс» и «Клип» отключены:** жанровые пакеты настроек ещё не
  описаны.
- **Модели не влезают в 6 ГБ одновременно.** Движок загружает их по
  очереди и освобождает память.
- **Частично использованные файлы в «Отбор» не входят:** там только то,
  что не попало в сборку вообще.
