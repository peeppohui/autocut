# AutoCut engine v2

Тонкий локальный движок для CEP-панели Premiere.

## Границы

- Панель не содержит логики монтажа. Она показывает состояние и шлёт команды.
- Движок не содержит UI. Он принимает папку, жанровый пак и ограничения,
  строит `edit_plan.json`, экспортирует XML и (позже) MP4.
- Никаких `ui/`, `mcp_server/` и отдельных режимов-клонов.

## Модули

| модуль | ответственность |
|---|---|
| `api.py` | HTTP для панели: здоровье, действие, задача, импорт XML |
| `jobs.py` | одна очередь тяжёлых задач, отмена, журнал |
| `actions.py` | дайджест, интервью, материал, доктор |
| `material.py` | разбор папки: части, файлы, секунды |
| `index.py` | единый индекс материала: сцены, речь, качество, описание, темы |
| `director.py` | структура истории и выбор кандидатов |
| `editor.py` | таймлайн: длительности, дорожки, ритм, ограничения |
| `packs/` | жанровые правила: дайджест, интервью, репортаж |
| `export/xml.py` | FCP7 XML для Premiere |
| `export/render.py` | MP4 через ffmpeg |
| `doctor.py` | проверка Python, ffmpeg, моделей и места на диске |
| `compare.py` | сверка `plan.csv` с эталонной секвенцией из `.prproj` (`python -m engine.compare plan.csv эталон.prproj Дайджест`) |

## Правило

Один жанр = один пак настроек, а не отдельная копия пайплайна.
Первый вертикальный срез — дайджест. Второй — интервью. Третий — репортаж.
