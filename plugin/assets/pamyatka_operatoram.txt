ПАМЯТКА ОПЕРАТОРУ (дайджесты и интервью, SVS Production)
Читать 2 минуты. Цель: чтобы монтаж не рвался на склейках.

ПОЧЕМУ ЭТО ВАЖНО
Монтажёр склеивает планы "через один": общий → средний1, средний2 → крупный.
Если снята только одна крупность — клеить не из чего, в ролике будут рывки.

ОБЯЗАТЕЛЬНЫЙ НАБОР С КАЖДОГО СОБЫТИЯ (снимай всё, монтажёр выберет)
1. Общий план зала/сцены — 5-8 сек, СТОЯ, без движения камеры.
2. Средний2 (человек по колени) спикера/ведущего.
3. Средний1 (человек по пояс) — то же действие, с другой точки.
4. Крупный (лицо) — эмоции, реакция, 2-4 сек.
5. Детали, 2-3 штуки по 2-3 сек: руки, награды, дипломы, аппаратура, экран.
6. Реакция зала — средний1, 3-4 сек.

ИНТЕРВЬЮ
- Две камеры — в ОДИНАКОВОЙ крупности (обе средний1, по пояс). Не "одна крупный,
  вторая общий" — иначе один герой будет "важнее" второго.
- Макушку не резать. Петличка включена, проверь уровень записи.
- Фон: без пересвета окон и без мусора за головой.

ТЕХНИКА (по следам наших роликов)
- Каждый план держи 5+ сек без зума и дёрганий. Нарезку сделает монтаж.
- Не записывай изображение с дисплея камеры: скобки автофокуса в кадре = брак.
- Проверь фокус на глазах перед интервью, а не по экрану впопыхах.
- Вертикаль снимай только если её просили отдельно.

ЧЕГО НЕ ДЕЛАТЬ
- Зум во время речи спикера.
- Один говорящий 15+ сек без смены плана — дай монтажёру перебивку (деталь/зал).
- Серия из 5+ одинаковых средних подряд — меняй точку или крупность.

Сдал карту → предупреди монтажёра, сколько камер и что где. Всё, ты молодец.
